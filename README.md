# MarketPulse Action Center

Prototype for the **Damm x Engineering HUB Hackathon**.

MarketPulse Action Center aims to help the UK commercial team understand whether the current month is on track, identify possible deviations from the monthly target, and explore commercial actions to reduce the gap.

> Detect the gap. Explain the cause. Recommend the action.

---

## Project goal

The goal of this project is to build a clear and explainable prototype for the **MarketPulse UK** challenge.

The challenge focuses on:

- Forecasting UK sales.
- Comparing forecasted sales against the monthly target or budget.
- Detecting deviations.
- Understanding possible causes.
- Including promotions in the analysis.
- Recommending commercial actions to help close the gap.

This repository is currently in the initial setup phase.

---

## Product idea

MarketPulse Action Center is not intended to be only a sales dashboard.

The objective is to create a decision-support tool that helps answer:

1. Are we expected to reach the monthly target?
2. If not, where is the expected gap coming from?
3. Which weeks, channels, brands or promotions may deserve attention?
4. What commercial actions could help improve the forecast?

---

## Initial scope

The first version of the project will focus on a simple end-to-end prototype.

Planned sections:

- **Executive Pulse**  
  High-level monthly status and key metrics.

- **Gap Diagnosis**  
  Explanation of the main drivers behind the expected deviation.

- **Demand Windows**  
  View of the best moments to take commercial action.

- **Action Planner**  
  Suggested commercial actions or recovery plans.

- **What-if Simulator**  
  Basic scenario simulation for promotions or commercial decisions.

The exact implementation may evolve during the hackathon.
